# Knownest 插件：翻译助手（translator）

> 翻译插件：对话即译 + 文档级翻译（译文落 sys-hub 工作空间 translator/translations/（收敛点批 2026-10-10，存量在「翻译/」），MD5 缓存命中秒回；面板一键直翻走免费快引擎）+ 领域方案术语包（软件/IT·学术·商务，翻译自动按对照执行）。

Knownest 官方插件的**社区分发仓**（消费型样板）——本仓内容为主仓 plugins/translator/ 的同步快照，tag 与市场版本一致（当前 v0.16.5）。

## 安装（插件市场 · 社区通道）

- Knownest → 插件市场 → **社区**：搜索「翻译助手」一键安装（GitHub topic `knownest-plugin` 自动收录）；
- 或在插件市场「更多安装方式」粘贴仓库地址：`https://github.com/bugjc/knownest-plugin-translator.git`。

## 仓库即样板

本仓即一份完整可运行的插件源：plugin.json（清单 + 权限 + i18n 词典）、index.js 入口、lib/ 实现（部分插件另带 golden-cases.json 黄金用例）。**Fork 本仓、改清单 id 与实现，即可发布你自己的 Knownest 插件。**
